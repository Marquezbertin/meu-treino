# Meu Treino 💪

App de treino (mobilidade, vídeos, esteira, escada e corrida de rua) em um único HTML — funciona offline e salva tudo no celular.

- **Abrir no celular:** https://Marquezbertin.github.io/meu-treino/
- **Arquivo:** `index.html` (igual ao `Treino.html`)
- **Instalar como app:** abra o link no Chrome (Android) ou Safari (iPhone) → menu → *Adicionar à tela inicial*.

Publicado com GitHub Pages a partir deste repositório.
